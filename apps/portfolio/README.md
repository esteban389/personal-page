# Portfolio

Minimal personal portfolio based on the visual and structural ideas of the
[Starfolio](https://github.com/webrating/starfolio) Astro theme.

The portfolio is intentionally a single-page site. It does not contain a blog;
all blog links point to <https://blog.estebanmurcia.dev>.

English is served at `/` and the complete Spanish version at `/es/`.

## Commands

Run from the repository root:

```sh
pnpm --filter @esteban/portfolio dev
pnpm --filter @esteban/portfolio check
pnpm --filter @esteban/portfolio build
```

Portfolio content is kept in `src/data/portfolio.ts`.
