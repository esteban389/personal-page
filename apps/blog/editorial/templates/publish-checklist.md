# Publication checklist

Phase 1 does not automate these checks. Do not treat this template as proof that a
check passed.

## Editorial

- [ ] Brief, outline, claims, draft, and review were explicitly approved.
- [ ] The final draft preserves the central thesis and human-authored judgment.
- [ ] The mandatory LLM-pattern audit is recorded and resolved.
- [ ] No unresolved blocker remains.
- [ ] Every important factual claim has an appropriate basis.
- [ ] Links, quotations, statistics, and code results were verified.

## Astro content

- [ ] Title, description, publication date, category, and draft state are correct.
- [ ] The slug is final.
- [ ] The hero image exists when configured.
- [ ] The hero-image direction, final asset, crop behavior, and alt text were approved.
- [ ] Article images have meaningful alt text.
- [ ] `##` and `###` headings provide the intended ToC structure.
- [ ] Editorial comments and internal claim IDs were removed.
- [ ] Code fences specify appropriate languages.

## Verification

- [ ] Formatting passed.
- [ ] `pnpm check` passed.
- [ ] `pnpm build` passed.
- [ ] The generated route was inspected.
- [ ] Pagefind indexed the article.

## Publication authorization

- [ ] Esteban explicitly authorized changing `draft` to `false`.
- [ ] Esteban explicitly authorized any requested commit or push.
