## Unresolved evidence questions

- No source blocker remains for the responsibility map above. The main unresolved
  decision is editorial: whether Java 25 structured concurrency adds enough value
  for a short preview sidebar or distracts from the stable API map.
- The selected `CompletableFuture` composition example is executable and models
  both a dependency and a join. Its final editorial depth remains subject to the
  author's review.
- Do not write a universal rule such as "always use the highest-level API,"
  "always use virtual threads for I/O," or "parallel streams are faster." The
  official contracts support narrower statements, and the correct choice depends
  on lifecycle, failure policy, workload, contention, ordering, and resource
  limits.
- Any performance statement beyond the documented qualitative boundaries requires
  a workload-specific reproduction or benchmark. None has been supplied, so the
  draft should make no measured speed or throughput claim.
